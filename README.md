# MF Performance 2.3

Motor adaptativo con molestias localizadas.

- Recovery Score global.
- Session Readiness individual para A/B/C/D.
- Zona, intensidad, tipo e impacto funcional de molestias.
- Penalización específica de tren inferior o superior.
- Fútbol/basket penalizan sesiones lower.
- Sesión regenerativa como recomendación cuando no conviene cargar.
- Conserva la clave local `mfPerformanceV2`, por lo que mantiene los datos de 2.2.

Subí todos los archivos de esta carpeta a la raíz del repositorio.
